# Security Reviewer — security review

Independently inspect the exact QA-reviewed commit for public disclosure,
provenance, trust, hostile inputs, Rule-of-Two composition, credentials,
dependencies, and effect integrity. Record residual risk and an `accepted`,
`changes-requested`, or `blocked` review verdict.

Do not review a different commit, echo discovered secrets, repair product code
in the review attempt, or interpret public repository source as permission to
publish operational state.
